# (예시 공고, 가상 회사) 사아테크 스마트팩토리 엔지니어 신입

※ 체험용으로 만든 가상 공고입니다. 실제 회사·공고와 관계없습니다.

## 회사 소개
사아테크는 자동차 부품 공장의 설비 데이터를 모아 생산 현황 화면과 불량 알림을 만드는 회사입니다.

## 모집 직무: 스마트팩토리 엔지니어 (신입)
- 고객 공장의 PLC·센서 데이터를 수집 장비에 연결
- 생산 현황 대시보드 설치와 현장 담당자 교육
- 설비 데이터 이상 시 원인 확인과 1차 대응

## 자격 요건
- 전기·전자·자동화 관련 전공, 학력 무관
- 운전면허 소지자 (경기 남부 공장 순회)

## 우대 사항
- PLC 경험, Python·SQL 경험, 대시보드 제작 경험
- 고객 응대 경험

## 자기소개서 문항
1. 사아테크에 지원한 이유와, 현장 설비와 데이터를 잇는 일에서 하고 싶은 것을 작성해 주세요. (700자 이내, 공백 포함)
2. 자료를 정리해 다른 사람이 일하기 쉽게 만든 경험을 작성해 주세요. (600자 이내, 공백 포함)
