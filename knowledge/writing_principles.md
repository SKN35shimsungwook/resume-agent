# 작성 원칙 (에이전트 프롬프트용)

에이전트는 이 파일을 단계별로 잘라서 프롬프트에 넣는다(`core/knowledge.py`).
규칙마다 id가 있어서, 검증기는 "어떤 규칙을 어겼는지"를 id로 보고한다.
근거 표기: `자N` = 자소서 영상 N번, `이N` = 이력서 영상 N번
([조사 보고서](../docs/research/2026-11-02-youtube-resume-cover-letter.md)). 게시 2026-11-02 기준.

영상 조언은 절대 규칙이 아니다. **최신 채용공고와 제출 양식이 항상 우선**한다 (자21, 이16, 이20).
