## 직무군 개요: 기술영업

- **하는 일**: 고객 발굴 → 미팅·니즈 파악 → 제안서·데모/PoC → 견적·입찰·협상 → 계약 → 사후관리·기술부서 협업.
- **세부 직무 차이**: IT·SW 기술영업은 매출 책임 + RFP·제안서·데모. 프리세일즈는 매출을 영업대표와 나누고 기술 디스커버리·데모·PoC·기술 Q&A가 중심. 전기·에너지 장비는 도면 이해 → 견적·원가 → 입찰 → 수주 → 납품·현장 대응. 일반 B2B는 아웃바운드·리드 발굴·CRM·파이프라인 관리.
- **핵심 증거 문법**: 고객 문제 → 기술 행동 → 결과(숫자) → 배운 점.
- **AI 경험의 무게**: IT·프리세일즈에서는 데모·PT 역량의 증거(상), 전기 장비에서는 보조.
- **당락 요인**: 기술 깊이보다 "이 기술이 왜 고객에게 필요한가"를 설명하는 능력. 자격증은 가점 정도라는 현직자 의견이 많다(전기 장비 중소업체는 예외).

## 확인 항목: 기술영업

공고가 요구하는 기본 요건이다. 못 채워도 지원은 한다. 매처는 충족 여부만 표시하고, 작성기는 부족한 요건을 먼저 꺼내지 않는다.

- **운전면허**: 전기 장비 영업은 사실상 필수(실제 운전 가능 여부까지)
- **전기 자격증**: 중소 수배전반 업체는 전기기사·전기산업기사·전기공사기사를 필수로 거는 사례가 있다
- **외국계 프리세일즈**: 4년제 졸업, 영문 이력서, PT 면접
- 대기업 공채는 어학 점수가 변별 요소라는 의견이 있다

## 작성 지침: 기술영업

**반드시**
- 모든 경험을 **고객 문제 → 기술로 한 행동 → 결과(숫자) → 배운 점**으로 쓴다.
- 기술 용어 뒤에는 반드시 고객 이점(돈·시간·위험)을 붙인다.
- "왜 이 산업에서, 왜 이 회사에서 영업인가"를 제품군·시장(예: 데이터센터·ESS)까지 내려가서 쓴다.
- 판매 실적이 없으면 "판매 준비"로 정직하게 쓰고, 타깃·문제·효과·가격을 정한 과정을 보여 준다.
- 효성형 단일 대형 문항(약 2,000자)은 "직무 역량 3~4개 소제목 + 각 경험 근거" 구조로 쓴다.

**금지**
- "소통을 잘합니다", "고객 만족도를 높이려 노력했습니다" 같은 자기 선언·추상 문장
- 개발자처럼 쓰기, 교육 과정 수료 자체를 핵심 역량으로 내세우기
- 한 자소서에 "AI 개발 + 전기 영업 + 일반 영업"을 다 넣어 초점 흐리기
- 기간·실적 부풀리기
