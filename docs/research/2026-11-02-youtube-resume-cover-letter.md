## 3. 공통으로 적용할 원칙

1. **공고를 기준으로 맞춘다.** 기업 일반론보다 채용공고의 직무·필수요건·우대요건을 먼저 읽는다.
2. **주장을 경험으로 증명한다.** 역량을 형용사로 선언하는 대신 상황, 본인의 행동, 결과를 간결하게 적는다.
3. **이력서와 자소서의 역할을 나눈다.** 이력서는 경력·역량의 빠른 탐색을 돕고, 자소서는 선택한 경험의 맥락과 판단을 설명한다.
4. **사실과 수치를 검증한다.** AI·예시·컨설팅 조언을 쓰더라도 본인이 설명할 수 없는 성과나 부풀린 수치는 쓰지 않는다.
5. **영상의 조언을 절대 규칙으로 보지 않는다.** 업종·직무·지원서 양식에 따라 달라지는 부분은 최신 채용공고와 제출 양식을 우선한다.

## 4. 확인 한계

- 영상 검색 결과의 제목·채널·상대적 게시 시점과 일부 설명·목차·유튜브 요약을 확인했다. 모든 영상의 전체 재생·자막 검증은 마치지 않았다.
- 제목에 포함된 합격률·순위·성과 표현은 검증된 통계로 취급하지 않았다.
- 게시 시점은 검색 화면이 제공한 상대 시점 또는 연도를 기록했으며, 표시되지 않은 정확한 날짜는 적지 않았다.
- 1~24번은 처음 선별본, 25~50번은 5장 보충 조사다.

### 보충 조사에서 새로 반영한 원칙

- **갈등·협업 문항**(자35~38): "경청했다", "역할을 나눴다" 같은 추상 해결 대신 실제로 바꾼 조율 행동과 결과를 쓴다 → `WR-9`
- **AI 활용 경험 문항**(자29, 자34): 새로 생긴 문항 유형. 도구 이름보다 무엇을 맡기고 무엇을 직접 판단·검증했는지 쓴다 → `WR-10`
- **짧은 경력·공백기**(이44~47): 직무와 관련 있으면 쓰고, 없으면 양식이 모든 경력을 요구할 때만 쓴다. 사유는 서류보다 면접 답변으로 준비한다 → `RS-9`
