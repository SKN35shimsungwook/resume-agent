# 자소서·이력서 유튜브 영상 조사 보고서

- 조사일: 2026-11-02
- 범위: 국내 구직자 대상 자소서·이력서 작성 영상
- 영상 확인: 유튜브 검색 결과에서 제목, 채널, 링크, 노출된 게시 시점 및 설명/목차/유튜브 요약을 대조
- 요약 원칙: 대본 전사가 아닌 재서술. 검색 화면의 제목·설명·목차로 확인되는 범위만 요약했으며, 영상 전체를 직접 시청해 확인했다는 뜻은 아님.
- 신뢰도 표기: `기관/전문가`는 대학·복지기관·공식 채용/미디어 채널·직업상담/헤드헌터/HR 이력 표시가 확인되는 자료, `실무/경험`은 개인의 취업 또는 채용 경험 중심 콘텐츠. 제목의 합격률 보장 표현은 사실로 간주하지 않음.

> **조사 상태:** 현재 확인 가능한 개별 영상 중 자소서 24편, 이력서 24편을 정리했다. 요청한 각 50편 기준에 미달한다. 검색 결과 반복 노출, 주제 이탈, 채널 배경이 확인되지 않는 짧은 영상은 채우기용으로 넣지 않았다. 50편씩 완성하려면 추가로 52편의 영상 검증과 요약이 필요하다.
>
> 이 보고서에서 뽑은 작성 원칙은 [knowledge/writing_principles.md](../../knowledge/writing_principles.md)에 규칙 id로 정리되어 있고, 에이전트 프롬프트가 그 파일을 읽는다.

## 3. 공통으로 적용할 원칙

1. **공고를 기준으로 맞춘다.** 기업 일반론보다 채용공고의 직무·필수요건·우대요건을 먼저 읽는다.
2. **주장을 경험으로 증명한다.** 역량을 형용사로 선언하는 대신 상황, 본인의 행동, 결과를 간결하게 적는다.
3. **이력서와 자소서의 역할을 나눈다.** 이력서는 경력·역량의 빠른 탐색을 돕고, 자소서는 선택한 경험의 맥락과 판단을 설명한다.
4. **사실과 수치를 검증한다.** AI·예시·컨설팅 조언을 쓰더라도 본인이 설명할 수 없는 성과나 부풀린 수치는 쓰지 않는다.
5. **영상의 조언을 절대 규칙으로 보지 않는다.** 업종·직무·지원서 양식에 따라 달라지는 부분은 최신 채용공고와 제출 양식을 우선한다.

## 4. 확인 한계

- 영상 검색 결과의 제목·채널·상대적 게시 시점과 일부 설명·목차·유튜브 요약을 확인했다. 모든 영상의 전체 재생·자막 검증은 마치지 않았다.
- 제목에 포함된 합격률·순위·성과 표현은 검증된 통계로 취급하지 않았다.
- 게시 시점은 검색 화면이 제공한 상대 시점 또는 연도를 기록했으며, 표시되지 않은 정확한 날짜는 적지 않았다.
- 보고서의 24+24편은 현재 확인된 선별본이다. 계획의 완성 기준(각 50편)에는 아직 도달하지 않았다.
